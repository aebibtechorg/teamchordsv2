# Admin Dashboard

## Overview
A React-based administration dashboard for platform management.

## Tech Stack
- **Framework:** React 19, Vite 7
- **Routing:** TanStack Router (File-based)
- **State Management:** TanStack Query / React Start
- **UI Components:** Shadcn UI, Radix UI
- **Styling:** Tailwind CSS 4
- **Auth:** Auth0 React SDK

## Conventions
- **Routing:** Routes are defined in `src/routes/`. The router configuration is in `src/router.tsx`.
- **Components:** Reusable UI components are in `src/components/`.
- **Styles:** Uses Tailwind CSS 4 with the `@tailwindcss/vite` plugin.
- **Types:** Strict TypeScript usage is required. Use `npm run typecheck` to verify.

## Development
- Run via .NET Aspire or `npm run dev` in this directory.
- Standard port: 3000.
