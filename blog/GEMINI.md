# Team Chords Blog

## Overview
The public-facing blog for Team Chords, built with Astro.

## Tech Stack
- **Framework:** Astro 6
- **Content:** MDX and Sanity (Headless CMS)
- **Styling:** Tailwind CSS 3
- **Deployment:** Vercel

## Conventions
- **Pages:** Located in `src/pages/`.
- **Components:** Reusable Astro/React components in `src/components/` (if any) or `src/layouts/`.
- **Content:** Sanity schemas are defined in the `studio/` subdirectory.

## Development
- Run via .NET Aspire or `npm run dev` in this directory.
- Standard port: 4322.
- Sanity Studio runs on port 3002.
