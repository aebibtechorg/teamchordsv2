# Billing

Billing is managed at the organization level.

Your current plan, subscription state, and renewal or end date appear on the **Billing** page.

## Plans

Team Chords currently presents these plans:

### Jam Session
- Free
- intended for individuals or small starter libraries
- includes limited chord sheets, set lists, and team members
- includes shared Live Mode updates for the set list view

### Gigging Band
- paid monthly plan
- supports larger libraries and unlimited collaboration
- includes musician-local transpose controls, offline access, and print/PDF support

### Pro Library
- paid monthly plan
- built for organizations that need the highest capacity
- includes everything in lower paid tiers plus higher capacity limits

## What the Billing page shows

The Billing page can show:

- your current plan
- subscription status
- renewal date
- cancellation-at-period-end state

Statuses may include:

- Active
- Canceled
- PastDue
- Incomplete
- None

## Who can manage billing

Only an organization admin should expect to manage billing actions like:

- opening the billing portal
- upgrading a plan
- canceling a subscription

If you are not an admin, ask an organization admin to make the change.

## Upgrading

If your organization is on the free plan, you can upgrade from:

- the **Pricing** page
- or the **Billing** page

Checkout uses the current organization context, so make sure the correct organization is active first.

Paid plan upgrades and downgrades now show a preview before they are submitted. The preview highlights:

- the immediate charge amount, if any
- when the plan change takes effect
- whether a downgrade produces an immediate charge or credit

This helps admins confirm both the price impact and timing before committing the change.

For downgrades, the preview and submitted change now reflect immediate prorated settlement, which may result in a credit instead of a charge.

## Billing portal

Paid plans can open the billing portal.

Use it to:

- review subscription details
- manage payment methods
- handle provider-managed billing tasks

The portal typically opens in a new browser tab.

## Canceling a subscription

Admins can cancel a subscription from the Billing page.

Important details:

- cancellation does not usually end access immediately
- access remains active until the end of the billing period
- the UI may show this as a canceled plan with remaining access

## After returning from checkout

If payment succeeds, Team Chords refreshes your profile so updated plan information can appear in the app.

If the UI looks stale, try:

- waiting a moment
- refocusing the browser tab
- refreshing the page

## Pricing page notes

The pricing page explains:

- monthly billing
- cancellation policy
- feature comparisons across tiers
- Jam Session includes shared Live Mode updates
- Gigging Band adds musician-local transpose controls, offline reuse, and print/PDF support

It also supports sign-in-aware checkout behavior.
