# Onboarding

This guide walks through the fastest way to get productive in Team Chords.

## 1. Sign up or sign in

Start from the public Team Chords site and create your account or sign in with your existing one.

If your team sent you an invite link, use that invite first. Team Chords will determine whether you should:

- go to **sign up** if you are new, or
- go to **sign in** if you already have an account

## 2. Create your organization

If you don't already belong to an organization, Team Chords will prompt you to create one.

You will be asked for:

- an **organization name**

After the organization is created, Team Chords refreshes your profile and takes you into the app.

## 3. Use the built-in product tours

Team Chords can seed onboarding tours for key areas like:

- the **Library**
- **Set Lists**

You can replay these tours later from your **Profile** page.

## 4. Add your first songs

Once your organization exists, go to **Library** and add content using one of these methods:

- create a new song manually
- upload `.chordpro`, `.cho`, or `.crd` files
- upload a `.json` backup

If you're migrating from another system, bulk upload is usually the fastest starting point.

## 5. Build your first set list

After your library has songs:

1. open **Set Lists**
2. create a new set list
3. add songs from the library
4. choose a target key and capo for each item
5. save the set list

## 6. Invite your team

From **Team**, admins can invite users by email.

Invited users can join your organization and start using the shared library and set lists.

## 7. Choose a plan if needed

Free accounts are a good starting point, but some teams will want a paid plan for:

- larger libraries
- unlimited set lists
- unlimited members
- live sync workflows

See **Billing** for plan details.

## Best practices for a smooth setup

- Create the organization first before inviting others
- Add a few test songs before importing your full library
- Standardize song titles and artist names early
- Use one shared organization per active team
- Build one test set list before a real rehearsal or service

## If you were invited to join an organization

When you open an invite link:

- Team Chords accepts the invite
- new users are sent to sign up with prefilled context
- existing users are sent to sign in

If the invite has already been used, the app will tell you.
