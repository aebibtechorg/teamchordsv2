# Help Center

## Overview
The public-facing help center for Team Chords, built with Docusaurus.

## Tech Stack
- **Framework:** Docusaurus
- **Language:** React / Markdown

## Conventions
- **Documentation:** Markdown files are located in `docs/`.
- **Sidebar:** Configuration is in `sidebars.js`.
- **Config:** Main configuration is in `docusaurus.config.js`.

## Development
- Run via .NET Aspire or `npm run start` in this directory.
- Standard port: 3001.
